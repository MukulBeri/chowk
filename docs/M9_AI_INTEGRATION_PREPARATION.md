## Image use and publication

Meta's API terms allow outputs in integrated products, allocate content rights between the parties subject to law, and retain user responsibility for inputs, output use and third-party rights. They also require eligible adult end users and compliance with applicable use/geographic policies. This is not a guarantee that an individual image is copyrightable or free of third-party claims. [Meta API terms](https://dev.meta.ai/legal/terms-of-service), reviewed 26 November 2026.

The AUP requires preservation of provider-applied watermarks, labels, metadata and provenance signals. A generated image or 160 KB derivative is not automatically publication-cleared; preserved lineage JSON alone does not prove all embedded signals survived. Review original/derivative, provenance handling, conceptual product accuracy and disclosure before expanding the current literal `unverified`/`private-experiment` asset policy. Keep original evidence private; do not simply flip its status. [Meta API AUP](https://dev.meta.ai/legal/acceptable-use-policy).
